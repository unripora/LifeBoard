# IMPLEMENTATION · 宿主实现自检

> 新增或修改插件协议能力时，按这份清单自查。**任一项不通过就不算完成。**

## 1. 契约

- [ ] Kotlin 契约与 `js-plugins/types/*.d.ts` 逐字段一致
- [ ] 新增能力已登记在 `JsHostFunctions`（若是 `ctx.*` 函数）
- [ ] 新增能力已加入 `HostCapabilities.ALL`，且本协议分册已同步
- [ ] 破坏性变更递增了 `apiVersion`；非破坏性变更**没有**递增

## 2. 兼容

- [ ] 旧插件（不声明新字段）行为不变
- [ ] 新字段缺省时有明确默认值，且文档写明
- [ ] 非法取值**拒载并给出原因**，而不是静默退化
- [ ] 旧宿主忽略新字段后，插件仍能安全降级（或明确拒载）

## 3. 生命周期

- [ ] 关键状态在业务过程中保存，**不依赖** `onUnload`
- [ ] 秘密只进 `ctx.credentials`，不进 `ctx.files`
- [ ] 运行时重建后能恢复；旧代际的迟到结果不会污染新实例
- [ ] 撤销信任/清除数据时**不**执行插件代码、不写回

## 4. 限额与故障

- [ ] 载荷限制在**读取阶段**生效（不是读完再判）
- [ ] 机器字段超限丢弃、展示文本按字符边界截断
- [ ] 同步死循环能被中断，且返回明确失败（不是"没有数据"）
- [ ] 连续故障停用可恢复，且不会因重扫复活

## 5. 观测

- [ ] 每类失败都有可分类的日志（错误码 + 操作 + 原因）
- [ ] 日志不含凭据、cookie、密码材料
- [ ] 用户可见文案说清"他能做什么"，而不是只报内部原因

## 6. 测试

- [ ] 契约测试覆盖新字段的缺失/非法/正常三种取值
- [ ] 双端（Android/桌面）都跑过，不是只在桌面验证
- [ ] 既有测试全绿；若有失败，能证明与本次改动无关

## 2026-11 已知边界

| 项 | 状态 |
|---|---|
| `onUnload` 文件写入 | **不开放**（原型未证明 2 秒内可停）；仅日志 |
| `runtime.lifecycle` 能力名 | 未列入 `requires`（回收默认关闭） |
| native 内存限额可配置 | 未实现（缺 C++ 工具链） |
| 真实插件登录恢复 | 仅验证宿主侧意图传递，插件侧待真机 |
